# Animation Enhancement Submission

## What
Added 34 new CSS animation classes covering entrance effects,
attention seekers, exit animations, and motion utilities.

## Why
Expands the animation library with smooth, hardware-accelerated
CSS animations using native keyframes and CSS custom properties.

## Files
- `style.css` - 34 keyframe animations with 24 CSS custom properties
- `demo.html` - Interactive showcase with 15 animated demo cards

## Usage
<link rel='stylesheet' href='style.css'>
<div class='ease-fade-in-up'>Animated content</div>

## CSS Custom Properties
Duration: --animation-duration-fast, --animation-duration-normal,
--animation-duration-slow, --animation-duration-slower, --animation-duration-slowest
Easing: --animation-easing-ease, --animation-easing-bounce, --animation-easing-smooth
Colors: --glow, --glow-secondary, --hue-primary, --hue-secondary
Shadows: --shadow-soft, --shadow-md, --shadow-lg
Borders: --border-radius-sm, --border-radius-md, --border-radius-lg
