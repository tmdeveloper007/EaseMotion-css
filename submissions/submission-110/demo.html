How to use

Add the stylesheet and apply animation classes to any element. Customize duration with CSS variables like --animation-duration-slow. All animations are hardware-accelerated and smooth.

Animation Categories

EaseMotion CSS covers entrance, attention, exit, and special animation effects. All classes use hardware-accelerated transforms for smooth 60fps performance.

Custom Properties

Override timing and colors globally: --animation-duration-slow: 1s, --glow: #ff6b6b. See the CSS file for all available variables.
